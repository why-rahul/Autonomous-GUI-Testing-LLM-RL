# Autonomous GUI Testing using LLM and Reinforcement Learning

An intelligent GUI testing framework that combines:

- Large Language Models (LLM)
- Reinforcement Learning (DQN)
- Selenium Automation
- OpenCV 
- Critic Agent for Self-Healing Testing

## Features

- Natural language test generation
- Autonomous UI interaction
- Bug detection
- Visual validation using OpenCV
- Reinforcement learning based decision making
- Multi-agent architecture

## Tech Stack

Python, Selenium, PyTorch, OpenCV, Ollama, LLM, Reinforcement Learning
